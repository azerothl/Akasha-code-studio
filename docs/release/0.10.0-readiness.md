# Préparation de la release Akasha Code Studio 0.10.0

État relevé le 23 octobre 2026. Le dépôt ne possède pas encore de release GitHub v0.10.0 et le registre npm ne renvoie pas de paquet akasha-code-studio. Aucun tag ni publication n'a été créé.

## Avant publication

- Valider la PR vers main et attendre la CI Linux/Windows.
- Publier Akasha v0.12.0 avant Code Studio : les nouveautés récentes du chat et du Kanban dépendent de cette version du daemon.
- Le relevé des secrets GitHub Actions ne montre pas de NPM_TOKEN configuré. Il faut le provisionner avant le tag, sinon la publication échouera. Le workflow de tag utilise ce secret et exécute le build de production.
- Vérifier le contenu généré avec npm pack --dry-run et tester l'installation publiée dans un environnement propre.
- Le dernier parcours Todo avec un vrai LLM n'a pas livré l'application : le Kanban et la reprise ont fonctionné, mais les tickets d'implémentation, les tests et l'aperçu n'ont pas tous abouti. Ne pas présenter cette version comme preuve que toute application est créée de façon autonome. Voir le rapport du 23 octobre dans docs/validation/inspection-handoff-vitest-real-2026-10-23.md.

## Déclenchement

Le workflow npm publish est déclenché par le tag v0.10.0. Il vérifie maintenant que le tag correspond à la version de package.json et utilise Node.js 22, conforme au champ engines.
