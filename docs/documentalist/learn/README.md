# Démarrer Code Studio

Démarrer le daemon Akasha, puis lancer Vite depuis ce dépôt. Ouvrir l’adresse affichée dans le terminal. Les tests de l’interface avec API simulée et les tests avec daemon réel sont décrits séparément dans le guide du dépôt.

```sh
npm install
npm run dev
```
